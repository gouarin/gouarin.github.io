- pylbm is a Python package for running numerical simulations with lattice Boltzmann methods easily.
- It is aimed at mathematicians, physicists and computer scientists.
- The strength of pylbm is to generate numerical code from symbolic mathematics according to what the user asks for. Several back ends are available: Cython, NumPy or Loo.py. pylbm supports MPI through mpi4py.
- It is used in a project funded by ESA (the European Space Agency) in partnership with CENAERO, the Von Karman Institute and the Orsay mathematics laboratory.
- We see 300 downloads per month.
